# Описание дизайна: личный кабинет / регистрация чеков

Текстовое описание макета как ориентир для вёрстки. Фокус на структуре блоков, составе и порядке полей, цветах и шрифтах. Отступы, тени, радиусы и иконки — приблизительно; пиксель-перфект не требуется.

Источник: скрины Figma («Тестовое задание. Разработчик»), десктоп ~1600px.

---

## Общая рамка (все экраны ~1600px)

**Тип:** десктопный личный кабинет промо/акции по чекам (светлая тема).

**Страница:**

- фон канваса — светло-серый / светло-голубо-серый (`#F3F4F6`–`#EEF1F6`);
- контент — белая карточка с крупным скруглением;
- сверху общая шапка на всю ширину.

**Шрифты:** один современный гротеск (Inter / Roboto / system-ui). Иерархия весами и цветом, не разными гарнитурами:

- заголовки экрана / модалки — крупный bold, почти чёрный / тёмно-синий (`#111827`–`#1E293B`);
- имя в шапке — semibold/bold, тот же тёмный;
- подписи полей и вторичный текст — regular, средний серый (`#6B7280`–`#9CA3AF`);
- плейсхолдеры — светлее основного текста;
- счётчики / акценты в числах — primary blue-violet.

**Цвета (примерно, со скринов):**

| Роль | Пример |
|------|--------|
| Primary CTA | `#4F56E8`–`#5B5FC7` (blurple) |
| Текст на кнопке | `#FFFFFF` |
| Фон карточек / шапки | `#FFFFFF` |
| Бордеры инпутов | светло-серый |
| Успех | яркий зелёный |
| Ошибка | красный бордер / текст / треугольник |
| Статус «В обработке» | жёлтый |
| Статус «Обработан» | зелёный |
| Статус «Ошибка» | красный |
| Статус «Вы выиграли» | фиолетовый |

## Общая шапка (повторяется)

Слева → направо:

1. **Плейсхолдер логотипа** — серый прямоугольник.
2. Ссылка **«‹ На сайт»** (серый текст, стрелка назад).
3. **Центральное меню** (иконка слева + текст):
   - **Личный кабинет** — активный: светло-серая «таблетка», иконка дома;
   - **Правила** — иконка документа/щита;
   - **Профиль** — иконка человека.
4. **Колокольчик** уведомлений (на пустом состоянии — с синей точкой).
5. **Блок пользователя:** круглый аватар → имя **«Елена Иванова»** → email **`nameuser@email.com`** (мельче и серее).

Шапка белая, отделена от серого фона страницы.

---

## 1. История чеков — пустое состояние

*Метка макета: «Личный кабинет / Незаполнен / 1600px»*

**Карточка контента:**

1. Строка шапки карточки:
   - слева заголовок **«История чеков»**;
   - справа бейдж-пилюля: **«Чеков внесено: 0 шт.»** (число / «0 шт.» — primary-цветом).
2. Центр — empty state (вертикальный стек, по центру):
   - иллюстрация чека + знак `$` + три «?» (светло-фиолетовые);
   - заголовок **«Здесь будет история ваших чеков»**;
   - подзаголовок **«Вы не добавили еще ни одного чека»** (серый);
   - primary-кнопка **«Зарегистрировать чек»** (иконка чека/+ слева, белый текст на blurple).

Таблицы нет.

---

## 2. История чеков — заполненное состояние

*Метка макета: «Личный кабинет / Заполнен / 1600px»*

Та же шапка + та же карточка.

1. Строка заголовка:
   - **«История чеков»**;
   - бейдж **«Чеков внесено: 24 шт.»** (число выделено).
2. **Таблица** (колонки слева → направо):
   1. мини-превью / QR-иконка чека;
   2. **Дата покупки** — формат `ЧЧ:ММ ДД.ММ.ГГГГ` (в макете плейсхолдер `00:00 00.00.0000`), в шапке колонки иконка сортировки;
   3. **Статус** — цветная пилюля (+ фильтр в шапке):
      - жёлтая — **«В обработке»**;
      - зелёная — **«Обработан»**;
      - красная — **«Ошибка»**;
      - фиолетовая (+ звёзды) — **«Вы выиграли»**;
   4. **Сумма чека** — иконка кошелька + `12 000 ₽`, сортировка;
   5. **Дата регистрации** — иконка календаря + тот же формат даты/времени;
   6. **Информация** — текст статуса / ошибки; у ошибок ссылка **«Подробнее»** primary-цветом.
3. Примеры строк в макете (порядок статусов): обработка → обработан (hover-ряд светлее) → обработан → ошибка (мин. сумма 1 000 ₽) → выигрыш → ошибка (магазин не в акции) → обработка → выигрыш.
4. Под таблицей по центру **пагинация:** стрелки + `1` (активная: primary-фон, белый текст) · `2` · `3` · `4` · `…` · `42`.
5. Низ карточки:
   - слева инфо-баннер (светло-фиолетовый): иконка `i` + **«Иногда проверка вашего чека может занять до 5 рабочих дней»**;
   - справа primary-кнопка **«Зарегистрировать чек»** (иконка +).

---

## 3. Модалка «Регистрация чека» (вручную)

*Метка: «Личный кабинет / Регистрация чека вручную / 1600px»*

Белая модалка по центру поверх серого фона; шапка страницы видна на заднем плане.

**Состав сверху вниз:**

1. Крестик закрытия справа сверху.
2. Заголовок **«Регистрация чека»**.
3. Подзаголовок **«Введите необходимые данные с чека»** (серый).
4. Форма — **5 полей строго в этом порядке** (лейбл сверху → инпут на всю ширину модалки; плейсхолдер серый):
   1. **ФН** — «Введите ФН»
   2. **Номер чека** — «Введите номер чека (ФД)»
   3. **ФП** — «Введите ФП»
   4. **Дата покупки** — «дд.мм.гггг чч:мм» + иконка календаря справа в поле
   5. **Сумма** — «0.00 ₽»
5. Primary-кнопка на всю ширину контента модалки: **«Загрузить»**.

Инпуты: светлый бордер, скругление. На этом экране обязательная звёздочка не показана (в отличие от отдельного error-инпута).

---

## 4. Сообщение об успехе + состояние ошибки инпута

### Успех после отправки

*Метка: «Сообщение об успехе после отправки» (~751×378 Hug)*

Центрированный вертикальный стек в белой карточке:

1. зелёная квадратная иконка с галочкой;
2. заголовок **«Ваш чек загружен»**;
3. текст **«Мы уже начали анализировать ваши покупки. Это займет всего пару секунд.»** (серый);
4. кнопка **«На главную»** (тот же primary blurple).

### Инпут в ошибке

*Метка: «Input 1600px» — паттерн поля*

Сверху вниз:

1. лейбл **«Телефон»**;
2. инпут с **красным** бордером, текст внутри красноватый («Placeholder / Error»), справа clear «×», снаружи у угла красная **`*`** (обязательное);
3. под полем «пузырь»/тултип с красной рамкой: иконка предупреждения + **«Ошибка! Текст ошибки»**.

## Что обязательно повторить при реализации

- Одну шапку на все экраны ЛК (лого · На сайт · 3 пункта меню · колокол · юзер).
- Два состояния истории: empty vs таблица + пагинация + инфо-баннер + CTA.
- Модалку с **тем же порядком полей:** ФН → Номер чека (ФД) → ФП → Дата покупки → Сумма → «Загрузить».
- Статусы четырёх цветов с теми же подписями.
- Primary один и тот же на всех CTA; success/error — отдельные семантические цвета.
- Лейблы полей видимые сверху (не только плейсхолдер); ошибка — рядом с полем, не только сверху формы.
